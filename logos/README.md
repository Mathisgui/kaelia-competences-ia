# Logos Kaelia

| Fichier | Usage |
|---|---|
| `logo-kaelia-color.png` | Défaut — en-têtes et pieds de page sur fond clair |
| `logo-kaelia-white.png` | Fond sombre (aubergine `#120031`) |
| `logo-real-white-bg.png` | Version détourée, fond blanc |
| `logo-real-dark-bg.png` | Version détourée, fond sombre |

Les générateurs embarquent leur propre copie dans `assets/` : ils la résolvent par
`__dirname`. Ce dossier est la référence pour un usage manuel.
